# Product

## Register

product

## Users

Mac users who need a dense, familiar desktop relational-database workspace similar to Microsoft Access without leaving macOS. They create tables, edit records, design queries, build data-entry forms, generate reports, and exchange database data locally.

## Product Purpose

Provide a local-first visual relational database studio for macOS. Success means a user can create and persist databases, define schemas and relationships, enter data, run and save SQL queries, use generated forms, print reports, and import Access data when compatible system tooling is available.

## Brand Personality

Professional, dense, familiar, pragmatic.

## Anti-references

Avoid consumer-style dashboards, oversized cards, decorative gradients, novelty navigation, browser-first styling, and misleading claims of perfect compatibility with proprietary Microsoft formats.

## Design Principles

1. Keep database objects and commands visible.
2. Make direct manipulation fast while retaining SQL power.
3. Prefer familiar desktop conventions and keyboard workflows.
4. Preserve user data explicitly and locally.
5. Communicate compatibility limitations honestly.

## Accessibility & Inclusion

Target WCAG 2.2 AA contrast, complete keyboard navigation, visible focus states, reduced-motion support, semantic labels, scalable text, and status messages that do not rely on color alone.
