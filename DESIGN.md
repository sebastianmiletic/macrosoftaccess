# Design System

## Direction

A dense native desktop database workbench designed for prolonged use on a MacBook in normal office lighting. The interface borrows the proven information architecture of ribbon-based database tools while retaining original branding and implementation.

## Color

Restrained light theme using subtly cool neutrals and a burgundy accent. Semantic states include success, warning, danger, selection, focus, and disabled. All colors use OKLCH tokens and maintain WCAG AA contrast.

## Typography

Use the macOS system stack. UI labels are 12-13px, object titles 15-18px, and compact tabular data 12px. Monospace system fonts are reserved for SQL and technical values.

## Layout

Desktop application shell with title bar, tabs, command ribbon, left object navigation, document tabs, central work surface, optional property panel, and status bar. Dense 28-34px controls prioritize information throughput.

## Components

Ribbon tabs and command groups, icon buttons, split buttons, object tree rows, document tabs, editable datasheet, SQL editor, query canvas, field inspector, generated record form, report preview, contextual empty states, inline dialogs, toasts, and status indicators.

## Motion

State transitions use 150ms ease-out. Respect reduced motion. No decorative animation.

## Accessibility

Visible 2px focus rings, keyboard shortcuts, ARIA labels, high-contrast selection, minimum 24px compact targets with larger primary actions, and non-color status cues.
